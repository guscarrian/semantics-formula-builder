# Semantics Notation Helper

A minimalist tool to help type and copy logic symbols and assignment formulas directly into Google Docs and Microsoft Word without messing up your formatting (or losing your sanity).

👉 **[Live Tool](https://guscarrian.github.io/semantics-formula-builder/)**

---

### Why this exists
Typing predicate logic formulas in word processors gets frustrating, especially when dealing with:
* Characters that are hard to find, like angle brackets ($\langle \rangle$), even in the equation toolbar.
* Complex nested indices like ($[\dots]^{M, g_x^{y}}$), where you need a superscript and a subscript on the same variable (which might already be a superscript itself!).

This page lets you build an expression by clicking symbols or typing, then copy the result so the formatting stays intact when pasted into Docs or Word.

### Features
* **Symbol Palette:** Quick access to connectives ($\land, \lor, \rightarrow$), quantifiers ($\forall, \exists$), sets ($\in, \subseteq$), and semantic brackets ([...], $\langle \dots \rangle$).
* **Two Modes:**
  * **Insert into workspace:** Build expressions in the box, then copy the whole formula.
  * **Copy symbol only:** Instantly copy single Unicode characters to your clipboard.
* **Shortcuts:** One-click insertion for common superscripts like $[ \cdot ]^M$, $[ \cdot ]^{M,g}$ and $[ \cdot ]^{M,g_x^{\text{val}}}$.
* **Clean Clipboard:** Pastes into MS Word and Google Docs without weird background highlights or text-box borders.
